✨ 豆包图片视频去水印

支持 豆包网页版自动识别当前会话的AI生成图片与视频然后进行去水印操作处理，最终支持一键下载获得高清豆包AI生成图片与视频 全部处理均在浏览器本地完成，不上传对话内容。

  • 🖼️ 豆包AI生成图片去水印
  • ✨ 豆包会话展示无水印图片与原始下载
  • 🎬 豆包AI生成视频去水印
  • 📑 图片与视频分栏管理
  • 📥 全部媒体资源一键下载

项目主页：DoubaoWaterMark-Remover 问题反馈：GitHub Issues

author：十一木。

🚀 使用方法

  1. 安装 Tampermonkey（或兼容管理器）。
  2. 在本页点击安装此脚本，确认脚本开关为开启。
  3. 打开 https://www.doubao.com，进入具体会话后刷新（建议 Ctrl + Shift + R）。
  4. 右下角出现蓝色面板即表示就绪；生成或浏览图片 / 视频后会自动收录到对应 Tab。
  5. 单项图片或视频直接「下载」，或一键下载点按钮「全部下载」；视频必须通过蓝色面板下载才能得到无水印视频

📷 界面示例

1. 加载就绪

打开豆包并进入会话后，如果加载成功可以看到右下角会出现一个蓝色面板

2. 图片：无水印 + 面板下载

在会话页面利用豆包AI生成图片可以直接在对话里面可以直接看到是无水印图片以及点击预览也是无水印图片可直接下载。

也可以通过蓝色页面看板下载图片

3. 批量下载图片

同会话多张图会汇总在「图片」，支持逐张或一键全部下载。

4. 视频

可管理当前会话的视频并进行去水印处理

⚠️注意：必须通过蓝色页面看板下载才能得到无水印视频,预览页面未处理会有AI生成或者豆包AI生成水印
