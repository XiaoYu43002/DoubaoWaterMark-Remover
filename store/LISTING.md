## 3. 详细说明（Description）＝商店页「概述」

别人商店页上看到的那段「概述」文字，就是你在后台填的 **详细说明（Description）**。  
不是另开一个字段；提交后会显示在扩展详情页的「概述」里。

下面按常见写法（一句口号 + 几段话）整理，整段复制到后台「详细说明」即可：

```
一个好用的豆包 AI 图片与视频无感去水印工具。

本扩展面向豆包（doubao.com）对话页，支持对 AI 生成的图片与视频进行无感去水印处理与原图/高清源下载。打开豆包后右下角会出现页内蓝色面板，显示「加载成功」即可开始使用；也可点击工具栏图标打开资源库，按会话管理并批量下载图片与视频。无需复杂配置，适合日常整理素材。

项目开源维护，代码与说明见 GitHub：https://github.com/XiaoYu43002/DoubaoWaterMark-Remover 。我们持续跟进豆包页面与接口变化，尽量保证解析稳定、下载顺畅。

本工具仅供个人合法学习与素材整理使用，不会收集你的聊天内容或隐私数据，媒体记录仅保存在本机浏览器。如需反馈建议或合作交流，可通过 GitHub Issues，或在扩展弹窗内复制微信号联系「十一木」。

我们会长期维护本扩展，并根据用户反馈持续优化解析速度与使用体验，欢迎安装试用。
```

## 6. 权限理由（Permission justification）

在 **隐私权规范** 页逐项粘贴（对应你弹窗里的报错）：

**单一用途（Single purpose）** — 见第 5 节。

**远程代码（Remote code）**  
若询问「是否使用远程代码」：选 **否 / No**（本扩展不从外网加载可执行脚本）。  
若仍要求填写理由，粘贴：
```
不使用远程代码。扩展所需脚本与 Wasm（opaque/xcodec.wasm）均打包在扩展包内随安装分发，运行时不从远程服务器动态加载可执行代码。
```

**downloads**
```
将用户选择的无水印图片与视频保存到本机下载目录。
```

**storage**
```
保存扩展偏好设置，以及本机会话媒体元数据（用于资源库列表），数据不离开用户设备。
```

**tabs**
```
识别当前豆包标签页与会话信息，以便正确归类图片/视频资源。
```

**主机权限（doubao / byteimg / snssdk 等相关域名）**
```
仅请求豆包站点与其媒体 CDN，用于捕获、解析与下载用户在对话中生成的图片与视频资源。
```

> 自 2.6.0 起扩展**不再申请 `debugger`**。若后台仍残留旧版 debugger 说明字段，可留空或删除该权限后重新上传 ZIP。

**政策确认**：勾选「确认数据使用符合《开发者计划政策》」。

## 8. 商店图片（你截图里那三项）

别人那种带大字标题、右侧悬浮面板的图，多半是 **屏幕截图**（或自己用 Canva 做的宣传向截图），不是「概述」文字。

| 后台字段 | 是否必填 | 尺寸 | 干什么用 |
|----------|----------|------|----------|
| **屏幕截图** | **必填**（至少 1 张，最多 5） | **1280×800** 或 640×400 | 详情页轮播；展示真实功能界面 |
